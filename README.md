# Pathfinder

Student placement readiness and analytics dashboard for BTech students.

## Features

- Placement readiness calculator using CGPA, backlogs, internships, communication, and coding confidence.
- Placement Analytics filters for year, course, gender, skill category, and AIML + Python cohorts.
- Course-wise and skill-wise placement charts.
- CSV export and printable PDF report export.
- Sample placement data for 2024, 2025, and 2026.
- Manus OAuth login and protected prediction features.

## Local development

```bash
pnpm install
pnpm dev
```

## Validation

```bash
pnpm test
pnpm check
pnpm build
```

The included 2024–2026 CSV is synthetic sample data for testing and should not be treated as official college placement data.
