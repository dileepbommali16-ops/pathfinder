# Pathfinder Platform Overview & Core Architecture

## Mission & Purpose
Pathfinder is a full-stack, enterprise-grade placement readiness platform. It combines predictive ML analytics, AI voice coaching, automated ATS resume parsing, and step-by-step project execution frameworks to help students qualify for top tech placement roles.

## Core Pillars
1. **Machine Learning Readiness Score**: Predicts placement probability using Random Forest modeling based on user profile inputs and metrics.
2. **DAS AI Voice Companion**: Real-time voice agent equipped with platform RAG knowledge, providing step-by-step project blueprints without context reset across page navigation.
3. **Branch-Tailored Academic Pathways**: Targeted roadmaps covering CSE, IT, AIML, CSD, ECE, EEE, Mechanical, and Civil engineering curriculums.
4. **Project Defense & ATS Engine**: Interactive mock viva technical probes paired with deep PDF/DOCX resume parsing for enterprise hiring standard alignment.
